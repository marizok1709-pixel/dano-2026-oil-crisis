## Подробно по каждой аномалии

## Критичность: КРИТИЧНАЯ

### `POST_TREATMENT_WINDOW`

**Таблица:** Таблица 1 — клиенты/автомобили  
**Затронуто:** 28 237 строк (100.00 %)  
**Что это:** fines_last_6/12/24/36_month пересекаются с периодом кризиса 2026 (корреляция с наблюдёнными штрафами 2026 = 0.75 против 0.45 с 2025).  
**Что сделали:** НЕ используются как контрольные переменные; вместо них — датированные помесячные колонки 2025

### `RIGHT_CENSORING`

**Таблица:** Таблица 2 — штрафы 2026  
**Затронуто:** 12 622 строк (16.19 %)  
**Что это:** Наблюдения с 2026-08-01: монотонное затухание 3176→1964→1605→597→4 в неделю вплоть до даты выгрузки. Это лаг регистрации, а не падение нарушаемости.  
**Что сделали:** Помечено; ИСКЛЮЧЕНО из всех расчётов по нарушениям. КРИТИЧНО: иначе получается ложный вывод «нарушения упали на 32%»

### `LEFT_TRUNCATION`

**Таблица:** Таблица 2 — штрафы 2026  
**Затронуто:** 3 032 строк (3.89 %)  
**Что это:** Наблюдения до 2026-04-01: суточное число растёт со 116 до плато ~401 — выгрузка отфильтрована по дате обработки постановления, а не по дате нарушения.  
**Что сделали:** Помечено; ИСКЛЮЧЕНО из всех расчётов по нарушениям

### `PRICE_MULTIMODAL`

**Таблица:** Таблица 3 — транзакции АЗС  
**Затронуто:** 10 594 строк (2.79 %)  
**Что это:** Распределение цены трёхмодальное: <50 ₽/л (газ, медиана объёма 45.6 л), 55–110 ₽/л (бензин/ДТ, 97.2%), >110 ₽/л (медиана 259 ₽/л при объёме 6.6 л — не моторное топливо).  
**Что сделали:** Разделено по тарифным группам. Основной анализ — только Бензин/ДТ. КРИТИЧНО: без этого газовые регионы ложно выглядят «освобождёнными» от лимита

**Что сделали:** Помечен; исключён из всех межгодовых сравнений 2025 vs 2026

**Что сделали:** Помечен; исключён из фиксированной когорты для расчёта ставок

**Что сделали:** Помечено; все ключевые результаты проверены с исключением этой категории

**Таблица:** Таблица 3 — транзакции АЗС  
**Затронуто:** 1 500 строк (0.40 %)  
**Что это:** Объём ≤ 0 л (минимум −164 л). Среднее −36.2 л зеркально среднему +36.0 л; равномерно по месяцам — это возвраты/отмены.  
**Что сделали:** Помечено; ИСКЛЮЧЕНО из агрегатов объёма и цены, строка сохранена в файле

### `DUP_VEHICLE_ROW`

**Таблица:** Таблица 1 — клиенты/автомобили  
**Затронуто:** 94 строк (0.33 %)

**Что сделали:** Оставлена строка с максимальным fines_last_12_month; вторая помечена и исключена из client-level агрегатов

## Как это влияет на выводы

| Аномалия | Если проигнорировать |
|---|---|
| `RIGHT_CENSORING` | Ложный вывод «нарушения упали на 32 % в августе». Самая опасная ошибка в этом датасете |
| `PRICE_MULTIMODAL` | Башкортостан, Самара и Татарстан ложно выглядят освобождёнными от лимита (на деле там просто больше газа) |
| `POST_TREATMENT_WINDOW` | Контроль на переменную, которая сама является следствием кризиса → смещение к нулю |
| `ENFORCEMENT_STEP_MAY` | Скачок фиксации ремней в мае приписывается топливному кризису. Даёт ~⅓ мнимого июньского эффекта |
| `NO_2025_BASELINE` | База 2025 занижена у 41,6 % строк → завышенный рост 2026 к 2025 |
| `LEFT_TRUNCATION` | Заниженный базовый период → завышенный «эффект кризиса» |
| `REVERSAL` | Средний объём заправки занижается; в июле среднее (31,1 л) уходит ниже медианы (34,8 л) |
| `DUP_VEHICLE_ROW` | Завышение штрафов 2025 на 0,29 % |

## Проверено независимо

Все аномалии перепроверены повторным чтением **исходных** файлов другим кодом (`v01`–`v03`).
Ключевые метрики воспроизведены из **экспортированных** файлов с нуля — совпадение полное.
