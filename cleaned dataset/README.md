## Прочитать первым делом — 5 правил

1. **Нарушения считаем только за 01.04.2026 – 31.07.2026.** Фильтр: `in_mature_window == True`.
   Август и сентябрь дадут ложное «падение нарушений на 32 %» — это лаг регистрации постановлений.
2. **Топливо считаем только по бензину/ДТ.** Фильтр: `in_analysis == True`.
   Без этого газ (31 ₽/л, 45 л) и не-топливные позиции (259 ₽/л, 6,6 л) исказят все средние.
3. **Знаменатель — фиксированная когорта, а не «активные клиенты месяца».**
   Число активных падает с 19 986 до 16 350 — это и есть эффект кризиса, делить на него нельзя.
4. **`fines_last_6/12/24/36_month` не использовать как контроль** — они пересекаются с кризисом.
   Вместо них — датированные колонки `apr_2025` … `aug_2025`.
5. **Ноль штрафов — это реальный ноль, а не пропуск.** 73,7 % клиенто-месяцев содержат ноль.

Полный разбор — в `docs/ДОПУЩЕНИЯ_И_ОГОВОРКИ.md`. Прочитать обязательно перед любым расчётом.

## Быстрый старт

```python
import pandas as pd
D = "data/"

panel = pd.read_csv(D+"05_panel_client_month.csv", sep=';')
fuel  = pd.read_csv(D+"04_fuel_transactions_clean.csv", sep=';', parse_dates=['order_dt'])
fines = pd.read_csv(D+"03_fines_clean.csv", sep=';', parse_dates=['offence_dt'])
cl    = pd.read_csv(D+"02_clients_level_clean.csv", sep=';', parse_dates=['subscription_dt'])

# фиксированная когорта для ставок
fix = set(cl.loc[cl.subscription_dt < '2026-04-01', 'client_id'])   # n = 23 452
N = len(fix)

# топливо: только бензин/ДТ, без возвратов
F = fuel[fuel.in_analysis & fuel.client_id.isin(fix)]

# нарушения: только зрелое окно, без дублей постановлений
V = fines[fines.is_kept_bill & fines.in_mature_window & fines.client_id.isin(fix)]

# контрольные значения — должны совпасть
base = F[(F.order_dt >= '2026-04-01') & (F.order_dt < '2026-06-19')]
cap  = F[(F.order_dt >= '2026-07-04') & (F.order_dt < '2026-07-28')]
print((cap.order_fuel_volume.sum()/24) / (base.order_fuel_volume.sum()/79) - 1)  # -0.3696
print(cap.order_fuel_volume.quantile(.9))                                        # 35.62
print(cap.order_fuel_price_1liter.median()/base.order_fuel_price_1liter.median()-1)  # +0.0230
```

Если эти три числа не совпали — что-то не так с фильтрами.
